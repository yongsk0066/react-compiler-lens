## View Compiled Output

Click any **Optimized** CodeLens label to see what the React Compiler generates.

The compiled output opens in a **side tab** (like Svelte's compiled view), showing:
- How the compiler memoizes your component
- Cache slots (`$[0]`, `$[1]`, ...) for dependency tracking
- Outlined functions for effects and callbacks

> **Tip:** Change the view mode in settings: `reactCompilerLens.compiledOutput.viewMode` (`"side"` or `"peek"`)
