## Open a React Component

Open any `.tsx` or `.jsx` file in a React or Next.js project.

**CodeLens annotations appear automatically** above each component showing:

- **Client Component** / **Server Component (default)** — component type
- **Optimized** / **Not Optimized** / **Skipped** — compilation status
- **reactive: count, filter** — which values trigger re-renders

> No configuration needed! The extension detects your framework automatically.
